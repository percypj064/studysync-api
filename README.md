# StudySync API

API REST para gestionar grupos de estudio.

## Tecnologías

- Node.js
- Express

## Endpoints

GET /api/grupos

GET /api/grupos/:id

POST /api/grupos

PUT /api/grupos/:id

DELETE /api/grupos/:id

GET /api/grupos/buscar/:materia

## Ejecutar proyecto

```bash
npm install
npm start
```
